# C1-G5F — ライブラリ内の疎構造特徴量・汎化準備監査

**2026-11-14 / `develop/0.10.0` pre-checkpoint HEAD `fc32f4a`**。
C1-G5C/DのRust内蔵Shadow Selectorを拡張する研究専用の観測機能であり、数値選択・収束モデルの承認ではない。

## 実装範囲

- `hybit-auto/src/c1g5f_feature_audit.rs` に、`HybitSolver::shadow_audit_csr32_with_model` を追加。`c1g5c-shadow` featureでのみ利用できる。
- 実行時のCSR係数とRHSに限って観測する。CSV/JSON、学習コーパス、Matrix Market入出力、Python、環境変数、既知の行列名は、**Rustライブラリの選択経路に入れない**。
- 既存 `ShadowRuntimeFeatures` とモデル診断の結果に加え、非対角成分の正符号率、対角非優位行数、最大非対角／対角比、正規化強結合率を提供する。
- 強結合は `|a_ij| / sqrt(a_ii a_jj) >= 0.25` で定義し、正の完全対角がない場合は該当特徴量を `None` とする。比率が非有限になる極端な数値例も `None` とし、正常値へ偽装しない。
- 既存V1モデルのバイナリ・重みの契約を**変えない**。追加した特徴量は将来の独立検証向けであり、モデル推論・費用予測・本番ルーティングにまだ使用しない。

## 証拠の扱い

- C1-G4/G5B: 3つの合成スカラー拡散行列、72+24件だが共通四方式の同一経路比較ではない。
- C1-G5E: 3つの独立した合成平面ひずみ弾性行列、48件・共通四方式、32件収束、16件非収束。
- したがって**合成FEM生成ファミリーは2、共通四方式計測が揃う生成ファミリーは1、独立外部物理ファミリーは0**。held-outで学習済みモデルを認証した実績はない。
- `C1G5F_CORPUS_COVERAGE_20261114` はこの不足を説明する**記録**にすぎず、選択器の自動有効化フラグではない。
- ユーザー側 `~/mtx` から2ファミリー6行列を読み込むのは開発用**example**であり、ライブラリ内ではパスもコーパスも扱わない。`b=A*1` に固定した診断表示は説明的であり、製造解・行列IDはモデルに入力しない。

## 認証・安全上の制約

- 対称行列・正の対角はSPD証明ではない。数学的クラスの宣言、適格性、元CSRの残差認証、メモリ予算、実際の収束退行は別ゲート。
- 特徴量のスキャンは O(nnz + n) 時間、O(n) 対角スクラッチを要する。実際に選択に用いる場合は、この費用を時間・メモリ総予算へ計上する。
- `ShadowFeatureAudit` 内の `model.base.recommended` は未承認のため `None` のまま。外部モデルの `diagnostic_candidate` は意味ある収束保証・時間予測・実行方式選択ではない。
- 既定 `hybit::solve()`、`HybitSolver::solve_csr32()`、公開C ABI、feature-off経路を変更しない。native Multilevelは依然研究用。

## 次の科学的ゲート

物理的なFEM行列/RHSを追加し、ファミリー単位のheld-out予測と、反復計測・準備済みRHS再利用・メモリ制約・偽収束防止を評価する。**C1-G5Fは特徴量観測の基盤であり、本番用の学習済み選択器ではない。**
