# H1-C3K8-D3: per-rank MPI Halo diagnostics & ABBA A/B

Pinned base: `develop/0.9.0`, `14ee3e26bb00d07c9faf3a6c4d541f77a67cd3a7` (D2).

## Experiment scope

- Preserves `spmv_assignment` and original D1/D2 examples. Adds only a read-only Halo metadata accessor and isolated `mpi_k8d3_rank_abba` example.
- Reports per-rank cumulative **Alltoallv-inclusive** time and per-rank cumulative inner-product Allreduce time, as `|`-delimited vectors in one CSV field each, rank order 0..P-1.
- Reports each rank's logical values sent/received per SpMV, and nonzero send/receive peer counts. For one rank the counts are zero.
- Measures all rankwise phase totals before the *reporting* Allgather (added after the timed solve). Per-phase maxima are not additive and Alltoallv includes waiting, not just wire time.
- Checks `sum(sent_values)==sum(received_values)`. Does not claim wait time can be separated from MPI transfer without hardware-level tracing.
- Uses controlled ABBA order: Checked, Prevalidated, Prevalidated, Checked. Every run is a new `mpiexec` process, with warmups and repeats. Both modes must produce CSV-rounded identical true residuals, solution errors, iterations, SpMV/dot counts and ghost totals.
- Computes per-group median of two Checked/Prevalidated sample medians and the relative improvement. ABBA mitigates linear order drift but cannot eliminate run-to-run noise; use several rounds for confidence.

## Files

- `mpi_k8d3_rank_abba.rs`: isolated binary cloned from the validated D2 experimental example.
- `mpi_assignment_d3_insertion.rs.txt`: accessor added to `mpi_assignment.rs` via pinned insertion anchor, no change to existing SpMV algorithm.
- `bench-k8d3-rank-abba.ps1`: one `*_summary.csv`, 24 jobs by default (4 and 8 ranks, 3 policies, Jacobi, 4 orders).
- `APPLY_HYBIT_K8D3_RANK_ABBA.ps1`: exact commit+blob+SHA preflight, strict Clippy, tests, build, integrity, 7 staged paths, rollback on failure, never commit/push.

## Interpretation

A large rankwise `d3_exchange_skew_ms` indicates unequal cumulative Alltoallv times but not necessarily unequal underlying communication duration; peer waiting, OS scheduling and MPI process placement can contribute. Compare peer counts/volumes with exchange timing and repeat the ABBA sequence before optimization.

This first-stage profiler does not change collective communication patterns within timed PCG and is not a new production SpMV API. Windows MSVC + native Microsoft MS-MPI only. This package has not been compiled/tested on the user machine before the logs return.
